# 带话（dsh-relay）

QQ 里每个人各有一个会话：甲和「A 会话」说话，乙和「B 会话」说话，两边互不相通。
甲让 A 带话给乙时，A 用 `qq_send_text` 直接发出去，乙回了消息却只会进 B——B 没有前因，只好乱说。

这个插件做三件事：

1. **自动同步背景（默认，最要紧的那件）**：A 把消息发给「不是当前聊天对象」的人时，插件在消息真正发出去之后，把这条消息和来路塞进对方会话的待处理上下文。B 不会被打扰、不会主动说话，但乙下一次开口时，B 已经知道前因了。
2. **`qq_relay` 显式交接**：A 也可以把话交给 B 的会话，由 B 用自己的口吻发给乙。乙看到的是「甲说，今晚不去了」；B 从第一句话起就知道甲托了什么话。
3. **回话带回（这一轮新增）**：A 往乙那边发过消息之后，乙的下一条消息会被带回 A 的会话并唤醒 A——A 才知道「乙怎么回的」，需要的话由 A 转告甲。B 也可以随时用 `qq_relay` 把乙的话交回给 A。

## 自动同步

触发条件是「成功发出去了」（监听 `tools/result`，不是发送前），所以失败的消息不会留下背景。规则：

- 只对 QQ 会话（`qq-*`）生效。
- 群聊 → 目标房间 `qq-hub`；VIP 私聊 → `qq-vip`；其他私聊 → `qq-dm-<QQ号>`；都按 `updatedAt` 取最新代。
- 发给「自己这个房间」时不触发（B 给乙发不会反过来注入 B）。
- 注入用 `agent.inject(...)`：落盘、进待处理队列，**不唤醒、不额外调用模型**。
- 同一次发送按 `callId` 去重；目标会话不存在时只记日志，不报错、不打扰任何人。

注入的内容长这样（只告知，不要求对方做任何事）：

```text
【带话 · 自动同步 · 来自「QQ 2174007116」】

「QQ 2174007116」那边刚才给 QQ 3599612346 发了一句话，原样是：
> 今晚不去了，你们玩

这句话已经直接发到 ta 的窗口了，你不用再发一遍；ta 之后回你时，
知道它是「QQ 2174007116」那边托人带过来的就行。
```

## 回话带回

A 往乙那边发过一条消息（自动同步或 `qq_relay` 都算）之后，插件会在 30 分钟内等乙的下一条消息：

- 乙一开口，这条消息就被投进 A 的会话并**唤醒 A**（`followup`），文案写明「如果这是给甲的答复，用 `qq_send_text` 转告甲（附甲的 QQ 号）」。
- 同一次带话只带回一条，带回后即失效；超过 30 分钟不再回传。
- 群聊不回传（人多，噪音大）；只有私聊（`qq-dm-*`、`qq-vip`）走这条。
- B 手里始终有带话授权（交接时自动给 30 分钟），所以乙临时说「你帮我跟甲说一句」时，B 可以直接 `qq_relay` 回 A。

## 工具

`qq_relay({ to, text, isGroup?, from?, note? })`

- `to`：私聊填 QQ 号，群聊填群号。
- `text`：甲要带的那句话，原样放进来。
- `isGroup`：`true` 表示带给一个群。
- `from`：托话人的称呼，不填就用会话标题。
- `note`：可选的甲的原话/补充语境。

调用条件：甲的话里出现过关键词（默认 `转告`、`帮我跟他说`、`帮我跟她说`、`帮我告诉他`、`帮我告诉她`、`带个话`、`带句话`）之后的 10 分钟内才允许。
没有授权时工具报错，提示 A 先跟甲确认——防止 A 自作主张把话送出去。

## 交接之后

1. 插件把一段消息投进目标会话（`qq-dm-<QQ号>`、`qq-vip` 或 `qq-hub`，含 `-rN` 代际后缀）并唤醒它。
2. 那段消息写清了前因、要发给谁、以及「就按这句发」的成品文案。
3. 对方那一轮如果自己用 `qq_send_text` 发给了目标，插件不再插手。
4. 整轮都没发出去时，插件用同一个工具兜底代发同一句，并记一条日志。
5. 目标会话不存在时，工具报错，A 回甲「我联系不上他，你自己跟他说吧」。

## 配置

`cordis.patch.yml` 的行里可以覆盖：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 关掉后不注册工具与监听器 |
| `keywords` | 见上 | 允许带话的关键词 |
| `armTtlMinutes` | `10` | 关键词授权有效期（分钟） |
| `vipIds` | `[1571229771, 3599612346]` | 私聊被折叠进 `qq-vip` 的号 |
| `vipSessionId` | `qq-vip` | 上面那些人的会话 id |
| `hubSessionId` | `qq-hub` | 所有群聊折叠到的会话 id |

## 限制

- 只对 QQ 会话（`qq-*`）生效。
- 回话带回只认「乙的下一条私聊消息」，一次性；再往后的对话要靠 B 主动 `qq_relay` 或新的带话触发。
- 注入的正文截断到 600 字；图片、语音、表情只留一句「发的不是文字」，不转附件。
- 对方发不出去时（比如 QQ 渠道的发送闸门拒绝），兜底同样会被拒，只在日志里留下一行。
