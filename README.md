# 带话（dsh-relay）

QQ 里每个人各有一个会话：甲和「A 会话」说话，乙和「B 会话」说话，两边互不相通。
甲让 A 带话给乙时，A 直接发出去，乙回了消息却只会进 B——B 没有前因，只好乱说。

这个插件把「带话」改成**交接**：A 调 `qq_relay` 把话交给 B 的会话，由 B 用自己的口吻发给乙。
乙看到的是「甲说，今晚不去了」；B 从第一句话起就知道甲托了什么话。

## 工具

`qq_relay({ to, text, isGroup?, from?, note? })`

- `to`：私聊填 QQ 号，群聊填群号。
- `text`：甲要带的那句话，原样放进来。
- `isGroup`：`true` 表示带给一个群。
- `from`：托话人的称呼，不填就用会话标题。
- `note`：可选的甲的原话/补充语境。

调用条件：只有甲的话里出现过关键词（默认 `转告`、`帮我跟他说`、`帮我跟她说`、`帮我告诉他`、`帮我告诉她`、`带个话`、`带句话`）之后的 10 分钟内才允许。
没有授权时工具报错，提示 A 先跟甲确认——防止 A 自作主张把话送出去。

## 交接之后

1. 插件把一段消息投进目标会话（`qq-dm-<QQ号>`、`qq-vip` 或 `qq-hub`，含 `-rN` 代际后缀）并唤醒它。
2. 那段消息写清了前因、要发给谁、以及「就按这句发」的成品文案。
3. 对方那一轮如果自己用 `qq_send_text` 发给了目标，插件不再插手。
4. 整轮都没发出去时，插件用同一个工具兜底代发同一句，并记一条日志。
5. 目标会话不存在时，工具报错，A 回甲「我联系不上他，你自己跟他说吧」。

## 配置

`cordis.patch.yml` 的行里可以覆盖：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 关掉后不注册工具与监听器 |
| `keywords` | 见上 | 允许带话的关键词 |
| `armTtlMinutes` | `10` | 关键词授权有效期（分钟） |
| `vipIds` | `[1571229771, 3599612346]` | 私聊被折叠进 `qq-vip` 的号 |
| `vipSessionId` | `qq-vip` | 上面那些人的会话 id |
| `hubSessionId` | `qq-hub` | 所有群聊折叠到的会话 id |

## 限制

- 只对 QQ 会话（`qq-*`）生效。
- 交接是一次性的：乙再回消息不会自动带回去给 A。
- 对方发不出去时（比如 QQ 渠道的发送闸门拒绝），兜底同样会被拒，只在日志里留下一行。
- 不转发图片、文件、语音，只交接文字。
